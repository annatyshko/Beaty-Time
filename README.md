# BeautyTime — Система онлайн-запису до салону краси

**Призначення:** Хмарний вебзастосунок для автоматизації онлайн-запису клієнтів, керування графіком майстрів та операційного обліку салону краси.

## Структура репозиторію
- `docs/` — проєктна документація (картка проєкту, SRS, UML-діаграми, ER-модель).
- `src/` — вихідний код прототипу застосунку.
